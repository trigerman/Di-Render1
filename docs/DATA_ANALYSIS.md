# Local data analysis

New plots infer their arrangement: numeric measurement columns (including CTRL/TEST-style headers) become wide-format mean groups; IDs are excluded from suggested measures. A time/date column becomes X with a separate curve per numeric measurement column. Long time data use the group column for series; a category plus multiple measures becomes grouped bars. Explicit numeric X/dose headers suggest scatter plots. Names and types are hints, not proof of experimental design, and every mapping remains editable. The active plot option is highlighted without a separate suggested-mapping card. **SD is the default error bar setting** for new plots; saved error settings remain intact.

The comparison status above the preview distinguishes missing matching, missing group choices, uncomputable tests, hidden nonsignificant results and unsupported bracket layouts. A missing paired-ID mapping offers **Match corresponding rows** (column groups only) or a direct ID-column selection. “Show comparison brackets” controls display of computed comparisons; it does not calculate a test or invent a p-value. Brackets and stars also render on categorical line/area plots. Continuous time-series comparisons do not imply pointwise comparisons and require a categorical plot for bracket anchors.

**Help me choose a statistical test** explains Welch, Student, paired t, Mann–Whitney, Wilcoxon, ANOVA/Tukey, Kruskal–Wallis/Dunn and planned pairwise Welch comparisons. The choice follows independence/matching and the experimental question, rather than a normality guess from headers or a small sample. Holm is the initial correction; the preview identifies raw versus adjusted labels and the planned family size. Time-series points are not automatically treated as independent replicates. See the primary method descriptions for [independent t tests](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html), [paired t tests](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_rel.html), [ANOVA](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.f_oneway.html), and [Wilcoxon](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html).


Suggested types are at the top of the right sidebar. The inferred initial type is highlighted; choose another type to override it. The full Plot type list remains below. **Dot plot with cross bar** shows observations with a horizontal aggregate marker. **Dot plot with bar/column** shows observations over an aggregate column. **Bar / column** is the ordinary column chart. **Grouped bar** accepts row data with distinct X-group, Series and Value columns, or an X category column plus separate numeric series columns; it clusters series side by side within each X group and uses consistent colors per series. Column-header means alone are ordinary columns. Missing group/series combinations stay blank. Existing saved cross-bar and bar plots retain their stored type keys.

For measurements arranged in separate columns, choose **Data arrangement → Column names on X** (or **Plot column means**). Each selected numeric column becomes an X-axis group, with a mean bar and SD error bars initially. Uncheck identifiers or unrelated measurements; selected columns stay in table order. For example, `Control: 2, 4` and `Treatment: 0, 6, 12` produce means 3 and 6 with n = 2 and 3. Missing cells are excluded separately for each column, never replaced by zero. The preview shows each group's mean and valid-value count without requiring a statistical test. Entirely empty groups are omitted; lines and areas leave a gap at an empty selected column. Choose **Group and value columns** for row-wise groups, or **Replicate columns within groups** to pool selected replicate measurements by a group column. Tables with more than 50 numeric columns require explicit selection. Saved plots retain their original mappings until edited.

Use **Insert plot** in the toolbar or the **Data** tab. Import a CSV/TSV/text file, paste spreadsheet cells, or choose **Type values**. Files and pasted text follow the same parser. Confirm the delimiter, headers, decimal and thousands separators, date format, missing tokens and declared column types. Ambiguous numbers require confirmation. The virtual grid previews the first 150 rows with whole-table excluded-cell counts; plots and analysis use every row.

The Insert plot flow has **Choose data**, **Review data**, and **Design plot** steps. Use **Back** repeatedly or click an earlier step to return without losing the current data and plot settings. **Reset** clears the draft, selected file, typed cells, and settings and returns to Choose data; datasets and plots already saved in the figure are preserved. New data stays in the dialog until **Apply**, which inserts the data and plot together as one undoable change. Canceling discards the draft. A figure with saved data can open directly at Design plot; Back returns to the source choices.

Choose the plot and column roles explicitly. Supported types are bar/column, grouped bar, stacked bar, line, area, range, scatter, heatmap, box, violin, dot plot with cross bar, dot plot with bar/column, grouped dot plot, Cleveland and Manhattan. Defaults use column names and declared types; statistical tests remain an explicit choice. Duplicate X positions and heatmap cells require an aggregate. Missing cells stay missing. Tukey whiskers end on observed values, and outliers remain visible with points off. Singleton and constant violin groups display observations without density. Manhattan raw p-values outside [0,1] are excluded; zero is reported and capped at 300 on the −log10 scale.

Statistics are optional. Choose **One-way ANOVA** to test all plotted independent group means, then choose **Tukey HSD / Tukey–Kramer** or no post-hoc comparisons. The overall table and optional plot annotation report F, numerator and denominator degrees of freedom, p and eta-squared (table). Tukey reports q, mean difference A − B, adjusted p and simultaneous confidence intervals at 1 − alpha. Equal group sizes use HSD; unequal sizes use Tukey–Kramer. Both assume independent observations, approximately normal residuals and equal population variances. This is not a repeated-measures or two-way ANOVA: each X × series combination in a grouped plot is treated as a separate group, without estimating interactions.

Choose **specific pairs** using Group A and Group B. Selecting the second group immediately adds the pair and clears the pickers for the next pair. Remove individual pairs or use **Clear comparisons**. Alternatively choose **all pairs** or **against a control**. Grouped data also offer shortcuts to compare series within each X or X within each series. For Welch, Student, paired t, Mann–Whitney, Wilcoxon, pairwise Welch and Dunn, the selected pairs define the correction family (none, Bonferroni, Holm or Benjamini–Hochberg). Failed comparisons retain their place in that family. Pair identities persist across changes of test, pairing mode and appearance; missing selected groups require explicit repair. A new two-group test starts with that sole pair; larger sets require a pair choice. Kruskal–Wallis tests all plotted groups and optionally uses Dunn comparisons; with two groups, select a two-group test explicitly.

For Tukey, all possible pairs among all plotted groups define the family even when only selected pairs or control comparisons are displayed. Selection never changes its pooled error, adjusted p or intervals, and no extra Holm/Bonferroni adjustment is applied. Brackets always use Tukey-adjusted p; the raw p column is the corresponding unadjusted pooled-error t test. Overall tests and brackets can be displayed independently. Hiding brackets or nonsignificant comparisons changes display only. Pairwise tests are two-sided; the overall ANOVA F and Kruskal–Wallis H tests use their upper tails.

Paired tests require subject IDs unique within each selected group, checked before excluding missing measurements. Only complete subjects shared by each selected pair are tested, with matched and excluded counts per comparison. Unselected groups cannot cause pairing failures. For new non-time column-group analyses without an ID mapping, choosing a paired test defaults to matching the same source row. The matching rule is stated in the controls and preview and remains editable. Existing saved choices are preserved. Time-series tables require an explicit matching choice; missing cells never shift later matches. Replicate-column layouts cannot use row-order pairing because they do not identify one measurement per subject per group. Descriptive group summaries use all valid measurements, while paired tests use the matched subset; Wilcoxon additionally omits zero differences according to its documented method.

ANOVA requires at least two nonempty groups, positive residual degrees of freedom (total observations greater than group count), and positive pooled within-group variance. Singleton groups can use the error estimate pooled from the other groups, including for Tukey–Kramer comparisons; all-singleton designs remain uncomputable. This follows [SciPy's ANOVA requirements](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.f_oneway.html). Tukey supports at most 20 groups (190 full-family comparisons); alpha must be between 0.000001 and 0.999999. Calculations run locally in a cancellable worker. Studentized-range survival uses bounded numerical quadrature of its defining normal-range/chi-square mixture, validated against SciPy reference fixtures. See [SciPy Tukey HSD](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.tukey_hsd.html) and [NIST Tukey method](https://www.itl.nist.gov/div898/handbook/prc/section4/prc471.htm).

Long, wide, replicate-column and separate-series layouts feed the same statistical engine. In grouped charts, each observed X × series combination is a group; missing combinations are not invented. Comparison lanes follow actual plotted X positions, including interleaved long-table rows. Crowded bracket labels and spacing compact automatically while retaining every selected computable comparison and space for the data. A notice explains the reduced annotation size; the full statistics table and CSV remain available. Hiding annotations does not change the results. Only genuinely insufficient space for axis labels produces a frame-size diagnostic.

The results table, CSV, clipboard, layers and exported brackets use recomputed results from the same prepared observations. Descriptives include sample SD/SEM, type-7 quartiles and a t-based 95% confidence interval. CSV and clipboard prefix dangerous text before quoting while preserving numeric cells, including negative values. Original downloads preserve source text except its leading BOM and use a safe text-file extension.

A plot is an atomic native vector object. Drag or resize it; text and strokes preserve their display size. Use Style for quick changes or **Edit plot** for mappings and analysis. Replacing data preserves column mappings by name. Missing datasets or incompatible columns show an error frame, preserve the specification and suppress statistics until repaired. Undo/redo covers data and plot edits. Data used by plots cannot be deleted.

Sources, import provenance, mappings and settings stay in IndexedDB and portable `.obf.json` files. Nothing is uploaded. Keep portable backups before clearing browser data. Source content is immutable and bound to its SHA-256 id. Autosave uses state v5 and figure-record v2 when data is present, with source text written once to `openrender:data-source:v1:<id>`. Owner references and garbage collection commit in the same transaction as revisions/library changes. Older state v2–v4 and figure-record v1 remain readable; no-data figures retain v4/v1 envelopes. Undo shares source text separately from per-dataset provenance.

Parsing, analysis and heavy scene generation run in bundled same-origin module workers. Only the current request may update the UI. Loaded-font measurements feed a second worker layout pass; validated scenes are reused only for matching immutable content, read settings, columns, plot specification and effective frame size. Canvas changes stage completely before replacing the last valid figure.

Limits: 5,000,000 source bytes, 20,000,000 bytes per figure, 20 sources, 50 datasets, 100,000 rows, 500 columns and 1,000,000 padded cells. Each measure column can be mapped only once; derived observations are bounded before allocation. A figure allows 50 groups per plot, 190 planned comparisons, 20,000 marks per plot and combined plot budgets of 3,500 vector elements, 24,000 path commands, 20,000 text characters and 1,400,000 SVG bytes. Repeated plots and plots inside groups count in full. Dense marks are batched into bounded paths. Scene budgets apply before worker output reaches the live preview as well as before import, apply and resize commit.

The UI and local help include English and French data-analysis guidance. The preview grid has roving focus and arrow-key navigation, modal dialogs trap focus and return it on close, and background editor commands are inert while a dialog or heavy canvas update is active.

Development reference fixtures are pinned to SciPy 1.17.1 and R 4.5.2 adjustment semantics. R adjustment fixtures use independent exact rational arithmetic against the pinned upstream source; an R runtime was not invoked. Python, SciPy and R are not runtime dependencies. Regenerate statistics with `python tests/reference/generate_stats_fixtures.py`, ANOVA/Tukey references with `python tests/reference/generate_anova_fixtures.py`, adjustments with `python tests/reference/generate_padjust_fixtures.py`, and reviewed renderer snapshots with `node --import ./tests/register-source.mjs tests/reference/generate_plot_snapshots.mjs`.
